HLS Player

A live video player you can put on any web page, with an iframe or one script tag. It plays any HLS stream (a .m3u8 address): a GodwinMix channel's watch link, a CDN, anything. It makes no request except the stream and sends nothing anywhere. Source and licence on GitHub.

Script tag

What the stream needs

The viewer's browser fetches the stream, so it has to be at an address the viewer can reach, over https when your site is https, and it has to answer with an Access-Control-Allow-Origin header. A GodwinMix watch link sends that header; a CDN or proxy in front of it has to keep it.

Keys: Space or K plays and pauses, M mutes, F is full screen, L goes back to live.
