The first release.

* `player.html` and `player.js`: an HLS player any site can embed with an iframe or a script tag, on hls.js 1.7.3 with native HLS where the browser has no Media Source Extensions.
* The HLS Player panel for GodwinMix: every channel watch link, a preview, and Copy buttons for both snippets.

Every archive holds the same plugin; the platform in the name is there so the gallery can pick one. Install with `gmx plugin add psmux/godwinmix-hls-player`, or from the Plugins page.
